# Ícones dos aplicativos

Coloque aqui os ícones (PNG) de cada app, **com exatamente estes nomes**:

| Arquivo | App |
|---|---|
| `renda-facil.png` | Renda Fácil |
| `bioquiz.png` | BioQuiz |
| `equilibrium.png` | Equilibrium |
| `aluguel-facil.png` | Aluguel Fácil |

## Recomendações
- Formato: **PNG** quadrado (proporção 1:1).
- Tamanho: **512×512 px** (mesmo ícone enviado à Play Store funciona perfeitamente).
- Fundo: pode ser opaco; a página arredonda os cantos automaticamente.

Enquanto o PNG não estiver presente, a página mostra automaticamente um
ícone temporário com as iniciais do app (fallback via `onerror`).
